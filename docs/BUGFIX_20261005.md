# 2026-10-05 实际使用问题修复

## 本地已实现

- 日期不再仅由 UI 显示占位时间，默认日期写进表单；识别时间优先覆盖默认值。
- 首次连接读取真实字段；后续启动使用加密的账本缓存立即展示，主动刷新仍同步飞书。
- 保存、识别和选项请求携带账本标识；网关按标识处理，字段不匹配时重新校验。
- 切换成功后重新识别保留的原图；外部分享图片复制到私有缓存，避免切换后临时读权限失效。缓存图七天后在识别时清理。
- 请求可取消、有整体超时；识别失败保留图片及现有输入，可重试；新的截图不会被旧请求结果覆盖。
- 最近手动选择的选项在对应账本、对应字段中置顶。
- 飞书入口优先显式打开客户端，未安装时回退浏览器。编辑权限由登录的飞书账号和该文档权限决定，APP 不会改变协作权限。
- 通知服务开放系统绑定但仍受系统绑定权限保护，断连主动请求重连；支持通知多行内容，修正短组件名称识别和提醒权限状态。
- 页面监测以当前窗口识别来源，避免自身浮动按钮事件导致按钮消失；补充支付页关键词及窗口异常提示。
- 添加选项后更新缓存字段；展示具体失败原因，方便区分网络和飞书权限问题。

## 验证与未完成项

Android 单元测试和 debug 构建、网关回归测试已通过；网关测试包含旧当前账本指针下的显式账本保存与日期提交。

若支付应用本身没有产生系统通知，通知方式无法触发。页面无法提供可读无障碍文本或禁止截屏时，页面监测也不能保证自动识别；需要在具体失败页面上验证。
