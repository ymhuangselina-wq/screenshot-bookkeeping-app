# 隐私说明（邀请测试草案）

截图记账仅在用户主动分享图片时读取该图片。图片会在当次请求中经由 Cloudflare Worker 发送给阿里云百炼进行识别，不写入数据库、KV、对象存储、日志或飞书附件。

服务会保存飞书用户标识、加密后的授权令牌、账本定位信息、字段映射和每日识别次数，用于登录、写入用户授权的多维表格和额度控制。日志不记录图片、金额、用途、备注、表格链接或授权令牌。

用户可退出登录，也可在 App 中注销账户。注销会删除服务端账户、令牌、会话和账本映射，但不会删除用户飞书中的多维表格或已保存账目。

本文档为邀请测试草案，公开发布前需补充运营者名称、联系方式、数据保留期限和适用法律条款。
