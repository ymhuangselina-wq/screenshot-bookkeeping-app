# 截图记账 MVP 1.0

首个经过真机确认的公开稳定版本。

## 主要能力

- 从 Android 系统分享面板接收截图，也可从应用内选择相册图片。
- 识别支付结果、外卖订单、转账结果和单笔已支付订单详情。
- 显示识别结果，确认后写入飞书多维表格。
- 支持多个常用账本、字段顺序、必填项和单选/多选项管理。
- 服务地址与个人访问密钥由用户在应用内填写，发布包不预置私人配置。

## 发布信息

- versionName：`1.0.0`
- versionCode：`12`
- applicationId：`com.example.screenshotbookkeeping`
- 最低 Android 版本：Android 8.0（API 26）
